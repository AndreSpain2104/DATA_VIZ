# Dashboard de Conversiones a GNCV en Colombia

Este proyecto consiste en el desarrollo de un dashboard interactivo utilizando la librería Dash de Python, con el propósito de realizar un análisis descriptivo y visual de los datos relacionados con las conversiones de vehículos a Gas Natural Comprimido Vehicular (GNCV) en Colombia.

El proyecto fue realizado en el marco de la asignatura Visualización de Datos, como ejercicio académico orientado a la construcción de aplicaciones analíticas que integran técnicas de preprocesamiento, exploración y comunicación visual de información.

## Objetivos

*   Implementar una aplicación en Dash para la visualización de datos.
*   Explorar las conversiones a GNCV en Colombia desde una perspectiva temporal, geográfica y categórica.
*   Desarrollar gráficos interactivos que faciliten la comprensión de tendencias y patrones.
*   Poner en práctica principios de visualización de datos y análisis exploratorio.

## Funcionalidades

El dashboard incluye:

### Indicadores clave (KPIs):

*   Número total de conversiones.
*   Promedio mensual de conversiones.
*   Municipio con mayor número de conversiones.

### Visualizaciones dinámicas:

*   Gráfico de tendencia temporal con opción de promedio móvil.
*   Gráfico de barras con los 10 municipios con más conversiones.
*   Mapa interactivo con la distribución geográfica de conversiones.

### Filtros interactivos:

*   Filtro por año.
*   Filtro por departamento.
*   Botón para restablecer los filtros.

### Despliegue

*   En el codigo se usó la instrucción server = app.server, lo cual nos permite su despliegue en plataformas en la nube como Render, en nuestro caso.

### Conclusiones

Este proyecto constituye un ejercicio de aplicación de herramientas de visualización de datos interactivas en Python.
El dashboard desarrollado permite explorar, analizar y comunicar patrones relevantes en la adopción de GNCV en Colombia, integrando métricas clave y representaciones visuales que facilitan la interpretación de los datos.
